# Доска — лёгкая интерактивная доска для уроков

Онлайн-доска для уроков иностранных языков, которая не тормозит на слабых ноутбуках.
Без фреймворков и сборки: чистый JS на клиенте (~90 КБ без сжатия) и маленький Node.js-сервер
с одной зависимостью (`ws`). Данные хранятся в JSON-файлах — база данных не нужна.

## Что умеет

- **Бесконечная доска**: панорама (пробел + мышь, колёсико, тачпад, два пальца) и масштаб (Ctrl + колёсико, щипок).
- **Рисование**: ручка, маркер (полупрозрачный), ластик по штрихам.
- **Объекты**: текст, стикеры, фигуры (прямоугольник, эллипс, треугольник, ромб, линия, стрелка) с текстом внутри.
- **Медиа**: картинки (перетаскивание, Ctrl+V, авто-сжатие больших фото), PDF (страницами-картинками или файлом),
  аудио, видео-файлы, YouTube, ссылки, любые файлы.
- **Интерактивные упражнения** с проверкой ответов:
  - заполнить пропуски: `I [am] a student`, несколько верных: `[don't/do not]`, выпадающий список: `{is|*are|am}`;
  - тест с одним или несколькими верными ответами;
  - соединить пары (слово = перевод);
  - составить предложение из слов.
- **Совместная работа в реальном времени**: курсоры участников, видно, как другие рисуют,
  ответы ученика сразу видны преподавателю.
- **Ссылка для ученика** без регистрации: режим «редактирование» или «просмотр и ответы»; ссылку можно отключить или перевыпустить.
- **Блокировка объектов**: ученик не сдвинет фон и задания, но может на них отвечать и рисовать поверх.
- **Слайды и показ**: рамки становятся слайдами, режим презентации со стрелками.
- **«Вести за собой»** — ученики видят то же, что и вы; **«Собрать всех»** — переносит всех к вам; **лазерная указка**.
- Отмена/повтор, копирование/вставка между досками, дублирование досок как шаблонов (ответы сбрасываются),
  папки, обложки, экспорт/импорт доски в файл.

### Горячие клавиши
`V` выделение · `H` рука · `P` ручка · `M` маркер · `E` ластик · `T` текст · `N` стикер · `S` фигуры ·
`F` слайд · `L` указка · `Del` удалить · `Ctrl+Z / Ctrl+Shift+Z` отмена/повтор · `Ctrl+D` дублировать ·
`Shift+1` показать всё · двойной клик по пустому месту — текст, по упражнению — редактирование.

## Установка на сервер (Ubuntu 22.04)

1. В Cloudflare добавьте **A-запись** домена (например `doska.example.ru`) на IP сервера,
   **без оранжевого облачка** (DNS only). Подождите пару минут.
2. Зайдите на сервер и выполните:

```bash
ssh root@2.27.40.24
```

```bash
apt-get update && apt-get install -y git
```

```bash
git clone https://github.com/zxrubx/holst.git /root/holst && cd /root/holst
```

```bash
sudo bash deploy/install.sh doska.example.ru
```

Скрипт установит Node.js 20 и Caddy (HTTPS-сертификат Let's Encrypt получит сам),
создаст systemd-сервис `lesson-board` и ежедневный бэкап.

3. Откройте `https://doska.example.ru` и зарегистрируйтесь. **Первый** зарегистрированный аккаунт
   становится владельцем, после этого регистрация автоматически закрывается.

### Обновление

```bash
cd /root/holst && git pull && sudo bash deploy/update.sh
```

### Полезное
- Данные: `/var/lib/lesson-board` (доски, пользователи, загруженные файлы).
- Бэкапы: `/var/backups/lesson-board` (14 дней).
- Логи: `journalctl -u lesson-board -f`.
- Настройки — в `/etc/systemd/system/lesson-board.service`:
  - `SIGNUP=first|open|off` — регистрация только первого / открытая / закрытая;
  - `APP_NAME` — название в интерфейсе;
  - `MAX_UPLOAD_MB` — лимит размера файла (по умолчанию 100).
  После правки: `systemctl daemon-reload && systemctl restart lesson-board`.

## Локальный запуск

```bash
npm install && npm start
```

Откройте http://localhost:3000.
